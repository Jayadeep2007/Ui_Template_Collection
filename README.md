# UI Template Collection – AI Interfaces

## 🚀 About the Project

**UI Template Collection** is a collaborative web development project that showcases modern and emerging **AI interface designs**.

The project was developed as part of a **Web Technology UI Template Collection Hackathon**, where each team member designed and implemented a different AI-based user interface.

The goal is to create a collection of modern, responsive, and interactive UI templates using **HTML, CSS, and JavaScript**.

---

## 🤖 AI Interfaces Included

| No. | Interface | Description |
|---|---|---|
| 1 | 📄 AI Document Summarizer | Summarizes documents and presents important information in a simple interface. |
| 2 | 🔍 AI Search | Provides an AI-powered search experience for finding relevant information. |
| 3 | ✍️ AI Content Generator | Generates different types of content using an AI-inspired interface. |
| 4 | 💬 AI Assistant | Provides a conversational interface for interacting with an AI assistant. |
| 5 | 📊 AI Analytics Dashboard | Displays AI-powered insights and analytics using dashboard components. |

## ▶️ How to Run

### Option 1 — Open Directly

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Select any AI interface from the homepage.

### Option 2 — VS Code

1. Clone the repository.
2. Open the folder in **VS Code**.
3. Open `index.html`.
4. Use **Live Server** or open the file directly in your browser.
